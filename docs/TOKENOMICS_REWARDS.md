# $CLAUD Token Reward System

## Core Token Value
- 1 $CLAUD = 1/8th cent ($0.00125)
- All rewards structured in multiples of 8 for system consistency

## Reward Philosophy
The $CLAUD protocol implements a dual reward approach:
1. **Users** earn tokens through active engagement
2. **Creators** earn tokens through milestone achievements

This system incentivizes quality contributions while preventing abuse by decoupling per-use rewards from creation.

## User Engagement Rewards

### Tool Usage
| Action                                   | Reward            |
| ---------------------------------------- | ----------------- |
| Using an MCP tool                        | 8 tokens ($0.01)  |
| Using an MCP tool with analytics sharing | 16 tokens ($0.02) |

### Forum Engagement
| Action                          | Reward            |
| ------------------------------- | ----------------- |
| Creating a forum post (`touch`) | 16 tokens ($0.02) |
| Commenting on a post (`commit`) | 4 tokens ($0.005) |
| Upvoting content (`git add`)    | 4 tokens ($0.005) |

### Content Consumption
| Action                        | Reward           |
| ----------------------------- | ---------------- |
| Completing a video tutorial   | 8 tokens ($0.01) |
| Reading an article (verified) | 8 tokens ($0.01) |

## Creator Milestone Rewards

## Forum Flag System

### Primary Flags (Base Rewards)
| Flag                   | Reward             |
| ---------------------- | ------------------ |
| `--build`              | 16 tokens ($0.02)  |
| `--how-to`             | 24 tokens ($0.03)  |
| `--technical-question` | 12 tokens ($0.015) |
| `--discussion`         | 16 tokens ($0.02)  |

### Modifier Flags (Multipliers)
| Flag            | Multiplier |
| --------------- | ---------- |
| `--progress`    | 1.2x       |
| `--shipped`     | 1.5x       |
| `--open-source` | 1.3x       |

### Platform/Language Flags (Small Bonus)
| Flag Type                                         | Bonus               |
| ------------------------------------------------- | ------------------- |
| Platform flags (`--iOS`, `--android`, etc.)       | +2 tokens ($0.0025) |
| Language flags (`--python`, `--javascript`, etc.) | +2 tokens ($0.0025) |

#### Flag Rules
- Users may select 1 primary flag (required)
- Up to 2 modifier flags permitted
- Up to 3 platform/language flags permitted

## Reward Limitations


### Anti-Abuse Measures
- Daily earning cap: 800 tokens ($1.00) per user
- Periodic reward scaling based on user population
- Engagement quality verification required for all rewards
- All rewards subject to adjustment through community governance

### System Sustainability
This reward structure is designed to provide meaningful incentives while ensuring long-term system sustainability. All token rewards are subject to adjustment based on community growth, user feedback, and protocol governance decisions.
